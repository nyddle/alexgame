# 🎮 Игра "Кольца" (Rings Game)

Интерактивная 3D игра на Three.js с уникальной механикой движения по кольцам.

## 📝 Описание

"Кольца" - это стратегическая игра, где игрок управляет шариком, движущимся по системе взаимосвязанных колец. Цель игры - достичь финишной точки, преодолевая динамические препятствия и используя станции пересадки для смены колец.

## 🎯 Основная механика

### Движение
- Шарик постоянно движется по выбранному кольцу
- Скорость зависит от статуса кольца (нормальное, быстрое, медленное, заблокированное)
- Направление движения можно менять только на станциях пересадки

### Станции пересадки
- Желтые пульсирующие сферы на пересечениях колец
- Позволяют сменить направление движения
- Позволяют перейти на соседнее кольцо

### Статусы колец
1. **Нормальное** (голубое) - стандартная скорость
2. **Быстрое** (оранжевое) - удвоенная скорость
3. **Медленное** (синее) - половинная скорость
4. **Заблокированное** (красное) - движение останавливается

### Динамика игры
- Статусы колец меняются случайным образом каждые 3 секунды
- Блокировки автоматически снимаются через 2 секунды
- Нужно планировать маршрут с учетом меняющихся условий

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| **SPACE** | Сменить направление движения (только на станции) |
| **1-5** | Перейти на кольцо с номером 1-5 (только на станции) |
| **R** | Перезапустить игру |
| **Мышь** | Вращение камеры (зажать ЛКМ и двигать) |
| **Колесико** | Приближение/отдаление камеры |

## 🚀 Запуск игры

⚠️ **ВАЖНО**: Игра использует ES6 модули и требует запуска через HTTP-сервер. Прямое открытие `index.html` в браузере **НЕ РАБОТАЕТ** из-за политики CORS!

### 🎯 Быстрый старт

#### На macOS/Linux:
```bash
./start-server.sh
```

#### На Windows:
```bash
start-server.bat
```

Затем откройте в браузере: **http://localhost:8000**

### 📋 Ручной запуск сервера

Если скрипты не работают, используйте один из вариантов:

#### Python 3 (рекомендуется):
```bash
python3 -m http.server 8000
```

#### Python 2:
```bash
python -m SimpleHTTPServer 8000
```

#### Node.js:
```bash
npx http-server
```

#### PHP:
```bash
php -S localhost:8000
```

### ⚠️ Решение проблем

**Ошибка**: `Access to script from origin 'null' has been blocked by CORS policy`

**Решение**: Вы пытаетесь открыть файл напрямую. Обязательно используйте HTTP-сервер (см. выше)!

**Альтернатива для Chrome/Edge** (не рекомендуется):
```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --allow-file-access-from-files

# Windows
chrome.exe --allow-file-access-from-files

# Linux
google-chrome --allow-file-access-from-files
```

## 🎨 Особенности реализации

- Светящиеся кольца с эмиссивными материалами

- OrbitControls для управления камерой

## 🔧 Настройка и модификация

### Изменение сложности
В файле `game.js` можно настроить:
- `this.speed = 0.02` - базовая скорость шарика
- Интервал `3000` в `startStatusChangeSystem()` - частота смены статусов
- Статусы в `RING_STATUSES` - множители скорости

### Добавление новых колец
```javascript
const newRing = new Ring(this.scene, radius, position);
this.rings.push(newRing);
```

### Создание станций
```javascript
ring1.addStation(angle, [connectedRingIndices]);
const station = new TransferStation(this.scene, position, [ringIndices]);
this.stations.push(station);
```

## 🐛 Решение проблем

### CORS ошибка при запуске
**Проблема**: При открытии `index.html` напрямую появляется ошибка CORS.

**Решение**: Используйте скрипт запуска (`./start-server.sh` или `start-server.bat`) или запустите HTTP-сервер вручную.

### Скрипт не запускается
**macOS/Linux**: Дайте права на выполнение:
```bash
chmod +x start-server.sh
```

**Windows**: Запустите от имени администратора или используйте PowerShell.

### Python/PHP не найден
Установите Python 3 или используйте Node.js:
```bash
npx http-server
```
