# 🎮 Игра "Кольца" (Rings Game)

Интерактивная 3D игра на Three.js с уникальной механикой движения по кольцам.

## 📝 Описание

"Кольца" - это стратегическая игра, где игрок управляет шариком, движущимся по системе взаимосвязанных колец. Цель игры - достичь финишной точки, преодолевая динамические препятствия и используя станции пересадки для смены колец.

### 🔷 Конфигурация поля

Перед началом игры вы можете выбрать одну из **двух конфигураций** игрового поля:

#### 📐 Треугольная (регулярная)

Плотнейшая укладка (hexagonal close packing) - как бильярдные шары в треугольнике:

```
        О           ← ряд 1: 1 кольцо
       О О          ← ряд 2: 2 кольца
      О О О         ← ряд 3: 3 кольца
     О О О О        ← ряд 4: 4 кольца
    О О О О О       ← ряд 5: 5 колец
```

- **15 колец** в строгой геометрической структуре
- Каждое кольцо касается **2-6 соседей** (предсказуемо)
- Старт: верхнее кольцо
- Финиш: правое нижнее кольцо
- Идеально для **изучения механики** и **поиска оптимального пути**

#### 🎲 Нерегулярная (случайная)

Случайное расположение колец в пространстве:

```
    О     О   О
  О   О       О
    О   О   О
  О     О   О   О
```

- **~15 колец** в случайных позициях
- Каждое кольцо касается **минимум 2-х соседей** (непредсказуемо)
- Старт: центральное кольцо
- Финиш: случайное кольцо
- Идеально для **челленджа** и **новых маршрутов** каждый раз

**Общее для обеих конфигураций:**
- Все кольца **одинакового радиуса** (R = 2.0)
- Станции пересадки находятся **точно в точках касания**
- Автоматическое создание станций во всех точках касания

## 🎯 Основная механика

### Движение
- Шарик постоянно движется по выбранному кольцу
- Скорость зависит от статуса кольца (нормальное, быстрое, медленное, заблокированное)
- Направление движения можно менять только на станциях пересадки
- Старт: верхнее кольцо треугольника
- Финиш: правое нижнее кольцо

### Станции пересадки
- Желтые пульсирующие сферы в **точках касания** колец
- Позволяют сменить направление движения
- Позволяют перейти на соседнее кольцо
- Автоматически создаются во всех точках касания

### 🔄 Визуализация направления движения
На каждом кольце присутствуют **анимированные стрелки** (маркеры направления):
- **8 белых стрелок** равномерно распределены по окружности кольца
- Стрелки **вращаются** по часовой стрелке, показывая направление движения шарика
- **Скорость вращения** маркеров соответствует статусу кольца:
  - Быстрое кольцо → стрелки вращаются быстрее
  - Медленное кольцо → стрелки вращаются медленнее
  - Заблокированное кольцо → стрелки **красные** и неподвижные
- Маркеры имеют **пульсирующую прозрачность** для лучшей визуализации
- Анимация работает даже на **стартовом экране**, помогая понять механику игры

### Статусы колец
1. **Нормальное** (голубое) - стандартная скорость
2. **Быстрое** (оранжевое) - удвоенная скорость
3. **Медленное** (синее) - половинная скорость
4. **Заблокированное** (красное) - движение останавливается

### Динамика игры
- Статусы колец меняются случайным образом каждые 3 секунды
- Блокировки автоматически снимаются через 2 секунды
- Нужно планировать маршрут с учетом меняющихся условий

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| **C** | 🚀 Пересадка на соседнее кольцо (циклически, если несколько доступны) |
| **SPACE** | Сменить направление движения (только на станции) |
| **R** | Перезапустить игру |
| **Мышь** | Вращение камеры (зажать ЛКМ и двигать) |
| **Колесико** | Приближение/отдаление камеры |

💡 **Совет**: Нажимайте **C** несколько раз на станции, чтобы циклически переключаться между доступными кольцами!

## 🚀 Запуск игры

⚠️ **ВАЖНО**: Игра использует ES6 модули и требует запуска через HTTP-сервер. Прямое открытие `index.html` в браузере **НЕ РАБОТАЕТ** из-за политики CORS!

### 🎯 Быстрый старт

#### На macOS/Linux:
```bash
./start-server.sh
```

#### На Windows:
```bash
start-server.bat
```

Затем откройте в браузере: **http://localhost:8000**

### 📋 Ручной запуск сервера

Если скрипты не работают, используйте один из вариантов:

#### Python 3 (рекомендуется):
```bash
python3 -m http.server 8000
```

#### Python 2:
```bash
python -m SimpleHTTPServer 8000
```

#### Node.js:
```bash
npx http-server
```

#### PHP:
```bash
php -S localhost:8000
```

### ⚠️ Решение проблем

**Ошибка**: `Access to script from origin 'null' has been blocked by CORS policy`

**Решение**: Вы пытаетесь открыть файл напрямую. Обязательно используйте HTTP-сервер (см. выше)!

**Альтернатива для Chrome/Edge** (не рекомендуется):
```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --allow-file-access-from-files

# Windows
chrome.exe --allow-file-access-from-files

# Linux
google-chrome --allow-file-access-from-files
```

## 🎨 Особенности реализации

### Математическая модель
- **Плотнейшая укладка** (Hexagonal Close Packing) - оптимальное размещение окружностей
- Расстояние между центрами = 2R (внешнее касание)
- Вертикальное расстояние = R√3 для треугольной решетки
- Автоматическое определение всех точек касания
- Точное размещение станций в точках касания

### Визуальные эффекты
- Светящиеся кольца с эмиссивными материалами
- **Анимированные маркеры направления** (8 стрелок на каждом кольце)
  - Вращаются с разной скоростью в зависимости от статуса кольца
  - Меняют цвет на красный при блокировке
  - Пульсирующая прозрачность для плавной анимации
- Пульсирующие станции пересадки (желтые сферы)
- Подсветка активной станции при приближении игрока
- Вращающийся финишный маркер с анимированными кольцами
- Туман для создания глубины сцены
- Динамическое освещение
- Непрерывная анимация даже в меню (для демонстрации механики)

### Архитектура кода
- **Ring** - класс управления кольцом
- **TransferStation** - станция пересадки с анимацией
- **PlayerBall** - игровой шарик с физикой движения
- **Goal** - финишная точка
- **RingsGame** - главный класс игры с автогенерацией поля

### Технологии
- Three.js v0.160.0
- ES6 модули
- OrbitControls для управления камерой
- Математические функции для геометрии

## 🎓 Стратегические советы

### Общие советы
1. **Выберите конфигурацию** - треугольная для обучения, нерегулярная для вызова
2. **Используйте клавишу C** - циклическое переключение между кольцами на станции
3. **Следите за статусами** - используйте быстрые кольца для ускорения
4. **Избегайте блокировок** - вовремя переходите на другие кольца

### Треугольная конфигурация
1. **Изучите структуру** - посмотрите на треугольник перед стартом
2. **Оптимальный путь** - от вершины к правому нижнему углу обычно 4-5 пересадок
3. **Центральные кольца** - имеют больше соседей (до 6), больше вариантов пути
4. **Краевые кольца** - имеют меньше соседей (2-3), могут быть тупиками

### Нерегулярная конфигурация
1. **Исследуйте поле** - каждая игра уникальна
2. **Адаптируйтесь** - нет фиксированного оптимального пути
3. **Запоминайте тупики** - некоторые кольца могут иметь только 2 соседа
4. **Используйте цвет** - быстрые кольца помогут быстрее достичь цели

## 🔧 Настройка и модификация

### Изменение конфигурации поля
В файле `game.js` в методе `setupGame()`:

```javascript
const RING_RADIUS = 2.0;           // Радиус всех колец
const numRows = 5;                  // Количество рядов (5 рядов = 15 колец)
```

**Примеры конфигураций:**
- `numRows = 3` → 6 колец (1+2+3)
- `numRows = 4` → 10 колец (1+2+3+4)
- `numRows = 5` → 15 колец (1+2+3+4+5)
- `numRows = 6` → 21 кольцо (1+2+3+4+5+6)

### Изменение сложности
```javascript
this.speed = 0.02;                  // Базовая скорость шарика (в PlayerBall)
const interval = 3000;              // Частота смены статусов (мс)
RING_STATUSES.FAST.speed = 2;       // Множитель скорости для быстрых колец
```

### Автоматическое создание станций
Станции создаются автоматически во всех точках касания:
```javascript
// Система находит все пары колец, которые касаются друг друга
// и создает станции в точках касания
if (Math.abs(distance - RING_DISTANCE) < 0.1) {
    // Создать станцию
}
```

## 🐛 Решение проблем

### CORS ошибка при запуске
**Проблема**: При открытии `index.html` напрямую появляется ошибка CORS.

**Решение**: Используйте скрипт запуска (`./start-server.sh` или `start-server.bat`) или запустите HTTP-сервер вручную.

### Скрипт не запускается
**macOS/Linux**: Дайте права на выполнение:
```bash
chmod +x start-server.sh
```

**Windows**: Запустите от имени администратора или используйте PowerShell.

### Python/PHP не найден
Установите Python 3 или используйте Node.js:
```bash
npx http-server
```
